FILES

- style.css: colours, layout, and design

TO PREVIEW
1. Extract the ZIP file.
2. Open the bishir_g_portfolio folder.
3. Double-click index.html.

TO PERSONALIZE BEFORE SHARING
- In index.html, replace your-email@example.com with your real email address.
- Update the About section and Skills to match your real interests and abilities.
- The project cards are clearly described as concepts; replace them with real projects when you have them.

TO UPDATE THE LIVE NETLIFY WEBSITE
1. Open Netlify and select the timely-pithivier-3693ba project.
2. Open Deploys.
3. Upload the updated website folder using Netlify Drop or the deploy upload option available to your project.
4. Open the live site and test it on desktop and mobile.

This is a static website; no paid software is required to preview it.
